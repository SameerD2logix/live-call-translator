# Demo video script (about 3 minutes)

First check the competition rules: maximum length, required content (e.g. ElevenLabs features to show),
language, and submission format. Adjust the timings below to fit.

## Setup

- **Two machines:** yours (the freelancer: translator + Zoom/Meet) and a second laptop or phone (the "client").
- Record both sides: OBS on your machine (screen + system audio + mic), and the client side's screen.
- Use a demo account and demo email. Hide API keys, real client names and personal email. Close notifications.
- Run the setup wizard's loopback test and one practice call just before recording.
- The client-role person agrees to appear and knows a translation tool is used (say so on camera too).
- **Show real timing.** Don't speed up or tighten the translated audio. If you cut anything, use a visible cut.

## Storyboard

| Time | On screen | Say / happens |
|---|---|---|
| 0:00–0:20 | You on camera, then the problem in one line of on-screen text | (Urdu, subtitled) "I'm a freelancer in Pakistan. My work is good, but on English calls I freeze, and clients notice." |
| 0:20–0:35 | App call screen, routing diagram from the setup wizard | "Live Call Translator: I speak Urdu, my client hears English, in my own voice. It plugs into Zoom, Meet or Teams through a virtual microphone." |
| 0:35–1:40 | **Live call**, split screen: you (translator + call) and the client's view | You speak three Urdu sentences (intro, deadline, a question). The client replies in English. Show: the delay badge, the client hearing your English, the Urdu subtitle of the client's reply. |
| 1:40–1:55 | Transcript row → **Fix** | A sentence comes out wrong: type the correction in English; the client hears the fixed sentence. |
| 1:55–2:25 | Recording screen → consent → Settings | "It only ever uses my own voice. I record set sentences and the app checks they're really me reading them. I give explicit consent, and I can delete the voice and my account any time. No call audio or transcripts are stored." Show 2FA on. |
| 2:25–2:45 | Simple architecture graphic | "Built with ElevenLabs Scribe v2 Realtime for speech recognition, Instant Voice Cloning and Flash v2.5 for my voice, Eleven v4 for Urdu speech, and Claude for translation. Swappable for self-hosted models later." |
| 2:45–3:00 | Back to you | "For millions of freelancers, language shouldn't decide who gets the job." Show the product name and link. |

## Lines to rehearse for the live call (Urdu → expected English)

1. السلام علیکم، میں سام ہوں، میں نے آپ کے پروجیکٹ کی تفصیلات دیکھ لی ہیں۔ → "Hello, I'm Sam, I've reviewed your project details."
2. پہلا ورژن جمعہ کی شام تک تیار ہو جائے گا۔ → "The first version will be ready by Friday evening."
3. کیا آپ اسٹیجنگ سائٹ کی لاگ اِن تفصیلات بھیج سکتے ہیں؟ → "Could you send the login details for the staging site?"

Client replies (for the Urdu subtitles): "Friday works for me." · "I'll send the login details after this call." ·
"Can you also add a contact form?"

## If something fails while recording

Stop, check the delay badge and the gateway log, and record the take again. Don't present a staged or pre-recorded
translation as live; if you include a pre-recorded segment, label it on screen.
